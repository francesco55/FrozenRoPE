\begin{abstract}
Language models that use rotary position embeddings (RoPE) fail beyond their pretraining length. Extending them usually means fine-tuning all weights or applying a fixed rule such as YaRN. We ask how much of context extension is positional: can a \emph{frozen} model be extended by learning only how it encodes position? We extend OLMo-2-1B from 4k to 16k tokens by training per-band frequency scales, at model, layer or head granularity, together with a per-head attention temperature. This is at most ${\sim}$17k parameters, about 0.001\% of the model. Our best configuration is learned per head and starts from YaRN. Against grid-tuned YaRN, it lowers 16k perplexity on PG-19 from 21.4 to 15.1 and more than doubles RULER needle-in-a-haystack accuracy at 16k ($24.0 \rightarrow 53.1$), while staying within one point of the original model's 4k perplexity. We also find that perplexity alone does not predict long-range retrieval. Next, we test content-dependent slow-band coordinates (DaRoPE) and measure how much of the remaining gap requires changing the backbone weights.
\end{abstract}

\section{Introduction}

Nearly every open-weight language model encodes position with rotary embeddings (RoPE; \citealp{su2021roformer}), and nearly every one degrades sharply once its input exceeds the length $L$ it was pretrained on \citep{chen2023pi, peng2024yarn}. OLMo-2-1B \citep{olmo2024olmo2}, for example, is trained with $L = 4096$. Given a 16k-token book, its perplexity explodes, and it fails every RULER retrieval task \citep{hsieh2024ruler} at 8k and 16k, although the whole input fits in memory (Table~\ref{tab:main}). Pretraining at longer lengths is costly: self-attention compares every token with every earlier one, so its FLOPs grow quadratically with sequence length, and a 16k sequence costs 16 times the attention compute of a 4k one. Inexpensive context extension of existing models is a practical, widely shared problem.

\paragraph{Why it is hard.}
RoPE divides each head's query and key vectors into $d/2$ two-dimensional \emph{bands} and rotates band $j$ of the token at position $m$ by angle $m\theta_j$, where $\theta_j = b^{-2j/d}$. Only the difference in angle survives the dot product, so the attention logit depends on relative distance alone:
\begin{equation}
s_{mn} = \textstyle\sum_{j} \mathrm{Re}\big[\,q_{m,j}\,\overline{k_{n,j}}\,e^{\,i(m-n)\theta_j}\big].
\end{equation}
Fast bands cycle many times within $L$ and encode local order. \emph{Slow bands}, whose wavelength $2\pi/\theta_j$ exceeds $L$, never complete a rotation in training; beyond $L$ they take angles the model has never seen. A second problem remains even when the angles are fixed: with four times as many keys, each softmax spreads its mass more thinly, so attention becomes flatter than the model was trained on.

\paragraph{How obvious solutions fail.}
Position Interpolation (PI; \citealp{chen2023pi}) divides every position by $L'/L$, which keeps slow-band angles in range but also compresses the fast bands; it harms the model even at 4k. YaRN \citep{peng2024yarn} interpolates only the slow bands and sharpens attention with a temperature, but it applies one hand-designed rule to every head, and its default settings fall far short of settings found by a grid search on validation data (Table~\ref{tab:main}).

\paragraph{Task.}
We treat context extension as a parameter-efficient learning problem. Given a pretrained model with frozen \emph{backbone weights} $W$ (all of its original parameters) and native length $L$, we seek a small set of \emph{positional parameters} $\phi$, $|\phi| \ll |W|$, that change only how positions are encoded and let the model operate at $L' = 4L$:
\begin{equation}
\min_{\phi}\; \mathbb{E}_{x\sim\mathcal{D}_{L'}}\big[-\log p_{W,\phi}(x)\big],
\end{equation}
while preserving its behavior up to $L$. We learn a scale for each RoPE frequency and a per-head temperature (\S\ref{sec:method}), starting from exactly the original model. Beyond the practical goal, this asks a scientific question: \emph{how much of context extension is positional?} If training $\phi$ alone closes most of the gap to fine-tuning $W$, the length limit lies in how positions are encoded, not in the backbone weights.

\paragraph{Questions and progress.}
RQ1 asks what learning RoPE parameters per model, layer or head on a frozen backbone adds beyond tuned YaRN; RQ2 whether they can be learned from 4k sequences alone with PoSE position skipping \citep{zhu2024pose}; RQ3 whether slow bands should instead learn a content-dependent coordinate, as in DaRoPE \citep{levy2026darope}; and RQ4 which backbone weights must change to close what remains. RQ1 is complete on test data: every configuration with a learned temperature beats tuned YaRN on 16k perplexity, and the best one also on RULER (\S\ref{sec:results}). Passkey retrieval disagrees for this model, which we analyze in \S\ref{sec:results}. For RQ2, models trained on 4k text match long-data training up to 8k but fail to retrieve at 16k.

\subsection{Methods}
\label{sec:method}

\paragraph{Model.} We extend OLMo-2-0425-1B \citep{olmo2024olmo2}: 16 layers of 16 heads (no grouped-query attention), head dimension 128 (64 bands), RoPE base $b = 5\times10^5$, $L = 4096$.

\paragraph{Implementation.} We patch the Hugging Face OLMo-2 code \citep{wolf2020transformers}: instead of one rotation table shared by all layers, each attention layer rotates its queries and keys with its own parameters, where stock RoPE is applied. All positional parameters $\phi$ sit in one float32 module, and the backbone is frozen. PI and YaRN are fixed settings of this module; every learned mode starts as the stock model, with identical logits (unit-tested).

\paragraph{Learned frequencies.} Following LeRoPE \citep{karypis2026lerope} and AdaRoPE \citep{wang2026adarope}, each band's frequency gets a learned log-scale,
\begin{equation}
\hat\theta_{g,j} = e^{a_{g,j}}\,\theta_j,
\end{equation}
where $g$ sets the granularity: one vector for the model (\emph{shared}, as in LeRoPE; 64 parameters), one per layer (1{,}024), or one per head (16{,}384, as in AdaRoPE), started at $a = 0$ (stock RoPE) or at YaRN's frequencies.

\paragraph{Learned temperature.} Against dilution, each head multiplies its queries, and so its logits, by AdaRoPE's
length-dependent scale
\begin{equation}
\lambda_h(i) = \frac{1}{\tau_h}\Big[\ln\Big(1 + \frac{\max(i+1,\,L)}{L}\Big)\Big]^{\gamma_h},
\end{equation}
with $\tau_h, \gamma_h$ learned per head (512 parameters) and $i+1$ the number of keys query $i$ sees. With $\tau_h$ alone, the temperature is constant: sharpening that helps at 16k changes the model equally at 4k. The bracket is constant up to $L$ and grows beyond it, so $\gamma_h$ sets how much a head sharpens on long contexts, separately from $\tau_h$. Initialization: $\tau_h = 1, \gamma_h = 0$ ($\lambda_h = 1$), or $\tau_h = 1/f^2$ for the YaRN start ($f$: YaRN's attention factor).

\paragraph{PoSE.} To learn $\phi$ without long sequences, PoSE \citep{zhu2024pose} trains on 4k-token sequences whose position ids skip ahead: the sequence is split into two pieces at a random point, and the second piece's positions are shifted by a random offset, so relative distances span up to $L'$ while the model only ever sees 4k tokens. Unlike the original, which fine-tunes all weights and takes the second piece's text from later in the document, we train only $\phi$ and keep the text contiguous, skipping positions only. We use it for RQ2 (\S\ref{sec:results}).

\subsection{Data}
\label{sec:data}

Training and perplexity evaluation use PG-19 \citep{rae2020pg19},
a corpus of long English books (\texttt{emozilla/pg19} mirror; OLMo-2 tokenizer;
non-overlapping token chunks, tails dropped).
Split usage follows standard practice:
\begin{itemize}
    \item \textbf{Train:} 100 chunks of length $16{,}384$ (at most one per book; seed~$0$).
    \item \textbf{Validation:} learning-rate selection and the YaRN grid
    (50 chunks per length for perplexity).
    \item \textbf{Test:} final perplexity (50 chunks at each of $4$k / $8$k / $16$k).
\end{itemize}
Retrieval objectives are never used for training.
For long-context retrieval we use two synthetic benchmarks.
Passkey \citep{mohtashami2023landmark} inserts a random five-digit key into
repeated filler at a controlled depth; we score exact key recovery
(test: $750$ prompts, seed~$1$; validation: $150$, seed~$0$).
RULER \citep{hsieh2024ruler}: we evaluate the eight NIAH task variants
at $4$k / $8$k / $16$k (validation: $100$ samples per task and length, seed~$1234$;
test: $500$, seed~$42$), with prompts from RULER's scripts and official string-match
scoring under greedy decoding; inference uses our own Hugging Face code, since RULER's
vLLM pipeline cannot run our patched attention.

\subsection{Metrics}
\label{sec:metrics}

We report (i)~perplexity on PG-19 at $4$k / $8$k / $16$k
(lower is better; $4$k also checks short-context regression);
(ii)~passkey accuracy (overall and by length);
(iii)~mean RULER NIAH score (\%).
We treat a method as successful if it improves long-context PPL and retrieval over
strong training-free positional baselines while losing at most about one point of
$4$k PPL relative to the unmodified model.

\subsection{Training details and compute}
\label{sec:train-details}

We train only positional parameters (frequency scales and, when used, AdaScale
temperatures) with next-token cross-entropy on the $16$k PG-19 chunks
(batch size~$1$, $500$ steps, AdamW \citep{loshchilov2019adamw}, no weight decay, grad clip~$1.0$, bf16).
We sweep LR $\in\{10^{-2},3{\times}10^{-2}\}$ (and earlier $10^{-3}$) and select
the LR by validation PPL at $16$k.
Baselines include stock RoPE, Position Interpolation \citep{chen2023pi} (factor~$4$),
default YaRN \citep{peng2024yarn}, and grid-tuned YaRN
(factor~$4$, $\beta_{\mathrm{fast}}{=}64$, $\beta_{\mathrm{slow}}{=}2$,
attention factor~$1.2$).
Each training run takes about $12$--$15$ minutes on one $40$--$80$\,GB GPU
(A100 / L40S-class) on a university cluster; the $144$-setting YaRN grid about $50$ minutes.
Full test evaluation (PPL, $750$-prompt passkey, and RULER) is dominated by RULER
and typically takes from tens of minutes to a few GPU-hours per checkpoint.

Our remaining work follows the proposal's RQ2--RQ4 path and tightens evaluation.

\paragraph{Evaluation.}
We will broaden RULER beyond our current eight NIAH tasks, report per-task scores
rather than only averages, and extend the per-depth breakdown of Table~\ref{tab:depth}
from passkey to the NIAH tasks.

\paragraph{PoSE (RQ2).}
We will reimplement PoSE \citep{zhu2024pose} closer to the original recipe:
short contiguous chunks with deleted middle text (or multiple gaps), so skipped
position IDs correspond to skipped content.
Our current contiguous-text variant (\S\ref{sec:method}) then becomes an ablation
against true PoSE.
As an extra idea, we will try random/uniform gap sizes and ask whether gap
length should be chosen in an informed way (e.g., matching target relative distances)
without defeating PoSE's goal of cheaper short-sequence training.
We will log validation loss alongside training for these runs.

\paragraph{DaRoPE (RQ3).}
Learned frequencies still tie slow-band angles to position, so they grow without bound beyond $L$. Following DaRoPE \citep{levy2026darope}, each head will replace position $m$ on the slow bands with a learned, content-dependent coordinate
\begin{equation}
c_h(x_m) = L\,\sigma\!\Big(w_h^\top \tilde x_m + \alpha_h\,\mathrm{logit}\tfrac{m+0.5}{L}\Big),
\end{equation}
where $\tilde x_m$ is the RMS-normalized hidden state. The coordinate stays in $[0, L]$, so angles never leave the pretraining range, and content can bring related tokens close regardless of distance. At $w_h = 0$, $\alpha_h = 1$, $c_h(x_m) = m + 0.5$ for $m < L$, so training starts from the original model (${\sim}$525k parameters). DaRoPE has only been trained from scratch; we test retrofitting it onto a frozen model.

\paragraph{Analysis.}
To explain retrieval wins/losses, we will compare attention weights on
needle tokens for strong vs.\ weak configurations.
