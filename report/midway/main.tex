\begin{abstract}
Language models that use rotary position embeddings (RoPE) fail beyond their pretraining length. Extending them usually means fine-tuning all weights or applying a fixed rule such as YaRN. We ask how much of context extension is positional: can a \emph{frozen} model be extended by learning only how it encodes position? We extend OLMo-2-1B from 4k to 16k tokens by training per-band frequency scales, at model, layer or head granularity, together with a per-head attention temperature. This is at most ${\sim}$17k parameters, about 0.001\% of the model. Against grid-tuned YaRN, our best configuration (per head, started from YaRN) lowers 16k perplexity on PG-19 from 21.4 to 15.1 and more than doubles RULER needle-in-a-haystack accuracy at 16k ($24.0 \rightarrow 53.1$), while staying within one point of the original model's 4k perplexity.
\end{abstract}

\section{Introduction}

Nearly every open-weight language model encodes position with rotary embeddings (RoPE; \citealp{su2021roformer}), and nearly every one degrades sharply once its input exceeds the length $L$ it was pretrained on \citep{chen2023pi, peng2024yarn}. OLMo-2-1B \citep{olmo2024olmo2}, for example, is trained with $L = 4096$. Given a 16k-token book, its perplexity explodes, and it fails every RULER retrieval task \citep{hsieh2024ruler} at 8k and 16k, although the whole input fits in memory (Table~\ref{tab:main}). Pretraining at longer lengths is costly, since attention compute grows quadratically with length (16 times more at 16k than at 4k), so cheap extension of existing models is a practical, widely shared problem.

\paragraph{Why it is hard.}
RoPE divides each head's query and key vectors into $d/2$ two-dimensional \emph{bands} and rotates band $j$ of the token at position $m$ by angle $m\theta_j$, where $\theta_j = b^{-2j/d}$. Only the difference in angle survives the dot product, so the attention logit depends on relative distance alone:
\begin{equation}
s_{mn} = \textstyle\sum_{j} \mathrm{Re}\big[\,q_{m,j}\,\overline{k_{n,j}}\,e^{\,i(m-n)\theta_j}\big].
\end{equation} Fast bands cycle many times within $L$ and encode local order. \emph{Slow bands}, whose wavelength $2\pi/\theta_j$ exceeds $L$, never complete a rotation in training; beyond $L$ they take angles the model has never seen. A second problem remains even when the angles are fixed: with four times as many keys, each softmax spreads its mass more thinly, so attention becomes flatter than the model was trained on.

\paragraph{How obvious solutions fail.}
Position Interpolation (PI; \citealp{chen2023pi}) divides every position by $L'/L$, which keeps slow-band angles in range but also compresses the fast bands; it harms the model even at 4k. YaRN \citep{peng2024yarn} interpolates only the slow bands and sharpens attention with a temperature, but it applies one hand-designed rule to every head, and its default settings fall far short of settings found by a grid search on validation data (Table~\ref{tab:main}).

\paragraph{Task.}
We treat context extension as a parameter-efficient learning problem. Given a pretrained model with frozen \emph{backbone weights} $W$ (all of its original parameters) and native length $L$, we seek a small set of \emph{positional parameters} $\phi$, $|\phi| \ll |W|$, that change only how positions are encoded and let the model operate at $L' = 4L$:
\begin{equation}
\min_{\phi}\; \mathbb{E}_{x\sim\mathcal{D}_{L'}}\big[-\log p_{W,\phi}(x)\big],
\end{equation}
while preserving its behavior up to $L$. We learn a scale for each RoPE frequency and a per-head temperature (\S\ref{sec:method}), starting from exactly the original model. Beyond the practical goal, this asks a scientific question: \emph{how much of context extension is positional?} If training $\phi$ alone closes most of the gap to fine-tuning $W$, the length limit lies in how positions are encoded, not in the backbone weights.

\paragraph{Research questions and progress.}
RQ1 asks what learning RoPE parameters per model, layer or head on a frozen backbone adds beyond tuned YaRN; RQ2 whether they can be learned from 4k sequences alone with PoSE position skipping \citep{zhu2024pose}; RQ3 whether slow bands should instead learn a content-dependent coordinate, as in DaRoPE \citep{levy2026darope}; and RQ4 which backbone weights must change to close what remains.

\subsection{Methods}
\label{sec:method}

\paragraph{Model.} We extend OLMo-2-0425-1B \citep{olmo2024olmo2}: 16 layers of 16 heads (no grouped-query attention), head dimension 128 (64 bands), RoPE base $b = 5\times10^5$, $L = 4096$.

\paragraph{Implementation.} We patch the Hugging Face OLMo-2 code \citep{wolf2020transformers} so that each attention layer rotates its queries and keys with its own parameters. All of $\phi$ sits in one float32 module (PI and YaRN are fixed settings of it), and every learned mode starts with logits identical to the stock model (unit-tested).

\paragraph{Learned frequencies.} Following LeRoPE \citep{karypis2026lerope} and AdaRoPE \citep{wang2026adarope}, each band's frequency gets a learned log-scale, $\hat\theta_{g,j} = e^{a_{g,j}}\theta_j$, where $g$ sets the granularity: one vector for the model (\emph{shared}, as in LeRoPE; 64 parameters), one per layer (1{,}024), or one per head (16{,}384, as in AdaRoPE), started at $a = 0$ (stock RoPE) or at YaRN's frequencies.

\paragraph{Learned temperature.} Against flatter attention, each head multiplies its queries, and so its logits, by AdaRoPE's
length-dependent scale
\begin{equation}
\lambda_h(i) = \frac{1}{\tau_h}\Big[\ln\Big(1 + \frac{\max(i+1,\,L)}{L}\Big)\Big]^{\gamma_h},
\end{equation}
with $\tau_h, \gamma_h$ learned per head (512 parameters) and $i+1$ the number of keys query $i$ sees. With $\tau_h$ alone, the temperature is constant: sharpening that helps at 16k changes the model equally at 4k. The bracket is constant up to $L$ and grows beyond it, so $\gamma_h$ sets how much a head sharpens on long contexts, separately from $\tau_h$. Initialization: $\tau_h = 1, \gamma_h = 0$ ($\lambda_h = 1$), or $\tau_h = 1/f^2$ for the YaRN start ($f$: YaRN's attention factor).

\paragraph{PoSE.} For RQ2, PoSE \citep{zhu2024pose} trains on 4k-token sequences split at a random point, with a random offset added to the second piece's position ids, so relative distances span up to $L'$. Unlike the original, which fine-tunes all weights and takes the second piece's text from later in the document, we train only $\phi$ and keep the text contiguous.

\subsection{Data and metrics}
\label{sec:data}
\label{sec:metrics}

Training and perplexity use PG-19 \citep{rae2020pg19}, a corpus of long English books
(\texttt{emozilla/pg19} mirror; OLMo-2 tokenizer; non-overlapping chunks, tails dropped): 100 training chunks of 16k tokens
(at most one per book; seed~0), and 50 validation and 50 test chunks at each of 4k / 8k / 16k.
Retrieval is used only for evaluation, with two synthetic benchmarks.
Passkey \citep{mohtashami2023landmark} inserts a random five-digit key into
repeated filler at a controlled depth; we score exact key recovery
(750 test / 150 validation prompts; seeds 1 / 0).
RULER \citep{hsieh2024ruler}: we evaluate the eight NIAH task variants
at 4k / 8k / 16k (500 test / 100 validation samples per task and length; seeds 42 / 1234), with prompts from RULER's scripts and official string-match
scoring under greedy decoding; inference uses our own Hugging Face code, since RULER's
vLLM pipeline cannot run our patched attention.
We report PG-19 perplexity (4k also checks short-context regression), passkey accuracy,
and the mean RULER NIAH score.
We treat a method as successful if it improves long-context PPL and retrieval over
strong training-free positional baselines while losing at most about one point of
$4$k PPL relative to the unmodified model.

\subsection{Training details and compute}
\label{sec:train-details}

We train only $\phi$ with next-token cross-entropy on the $16$k PG-19 chunks
(batch size~$1$, $500$ steps, AdamW \citep{loshchilov2019adamw}, no weight decay, grad clip~$1.0$, bf16).
We sweep LR $\in\{10^{-2},3{\times}10^{-2}\}$ and select it by validation PPL at 16k.
Baselines are stock RoPE, PI (factor~4), default YaRN, and grid-tuned YaRN
(factor~4, $\beta_{\mathrm{fast}}{=}64$, $\beta_{\mathrm{slow}}{=}2$, attention factor~1.2),
chosen from 144 settings by validation perplexity and passkey accuracy, the latter on only
six prompts at 16k, so it may not be optimal.
A training run takes 12--15 minutes on one A100 / L40S-class GPU, the YaRN grid about
50 minutes, and full test evaluation, dominated by RULER, up to a few GPU-hours per checkpoint.

\section{Future Work}
\label{sec:future}
\label{sec:plan}
% Midway outline item 4, "Project plan". Source: report/midway_project_plan.tex.
% Still to mention: short-context benchmarks.

Our remaining work follows the proposal's RQ2--RQ4 path and tightens evaluation.

\paragraph{Evaluation.}
We will broaden RULER beyond our current eight NIAH tasks and compare more closely
to the official evaluation stack.
We will also break results down per task (not only averages) and plot
accuracy by needle depth/position for passkey and NIAH-style probes.

\paragraph{PoSE (RQ2).}
We will reimplement PoSE \citep{zhu2024pose} closer to the original recipe:
short contiguous chunks with deleted middle text (or multiple gaps), so skipped
position IDs correspond to skipped content.
Our current variant only inserts a gap in contiguous text (pushes neighboring tokens
apart without removing content); we will treat that as an ablation against true PoSE.
As an extra idea, we will try random/uniform gap sizes and ask whether gap
length should be chosen in an informed way (e.g., matching target relative distances)
without defeating PoSE's goal of cheaper short-sequence training.
We will log validation loss alongside training for these runs.
To test whether negative $\gamma_h$ causes the 16k failure, we will clamp $\gamma_h \geq 0$
at evaluation, which needs no retraining.

\paragraph{DaRoPE (RQ3).}
Learned frequencies still tie slow-band angles to position, so they grow without bound beyond $L$. Following DaRoPE \citep{levy2026darope}, each head will replace position $m$ on the slow bands with a learned, content-dependent coordinate
\begin{equation}
c_h(x_m) = L\,\sigma\!\Big(w_h^\top \tilde x_m + \alpha_h\,\mathrm{logit}\tfrac{m+0.5}{L}\Big),
\end{equation}
where $\tilde x_m$ is the RMS-normalized hidden state. The coordinate stays in $[0, L]$, so angles never leave the pretraining range, and content can bring related tokens close regardless of distance. At $w_h = 0$, $\alpha_h = 1$, $c_h(x_m) = m + 0.5$ for $m < L$, so training starts from the original model (${\sim}$525k parameters). DaRoPE has only been trained from scratch; we test retrofitting it onto a frozen model.

\paragraph{Analysis.}
To explain retrieval wins/losses, we will compare attention weights on
needle tokens for strong vs.\ weak configurations.

\paragraph{RQ4 (stretch).}
If learned positions still fall short, is the rest of the problem in the backbone weights?
To find out, we will unfreeze them step by step, first with LoRA \citep{hu2022lora} on the
query and key projections, then with full fine-tuning, and measure how much each step adds.
